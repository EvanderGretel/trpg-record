使用說明

第一次用？照順序看就好，每段都可以點開。

① 新增一筆記錄
  1. 點右上角「＋ 新增記錄」，表單會以彈出視窗出現。
  2. 劇本名稱一定要填，其他欄位之後再補也可以。
  3. 還沒跑完？結團日留空就好，會標成「進行中」。
  4. 按「新增」，記錄就會出現在下面的列表。
② 修改、複製或刪除
  • 每筆記錄右邊有三個小圖示：⧉ 複製、✏️ 編輯、🗑️ 刪除。
  • 按編輯時，表單會在畫面中央彈出，頁面不會被捲動，改完關掉就回到原本的位置。
  • 要一次刪很多筆 → 點「批量管理」，勾選後再按刪除（會先請你確認）。
③ 統計和圖表在看什麼
  • 右上角可切換年份，選「全部年份」就是全部。
  • 統計上方可切換 「已結團」／「進行中」：預設看已結團的，切到「進行中」就只看還沒填結團日的團務。
  • 「已結團」以結團日計算年份與月份；「進行中」則以開跑日計算，並統計至今已經跑了幾天。
  • 統計會分別列出人數分類與劇本類型的數量；圖表預設收起，按「展開圖表」才顯示。
④ 分類管理（人數／劇本類型）
  • 點列表工具列的「⚙️ 分類管理」，可以調整人數與劇本類型的選項。
  • 新增的分類會立即出現在表單與篩選選單中。
  • 重新命名會同步更新既有記錄的對應值；刪除分類後，既有記錄會保留原本的名稱（只是不再出現在選單裡）。
⑤ 找不到某筆記錄？
  • 搜尋框可以搜劇本名稱、系統、劇本類型、備註。
  • 旁邊的選單可以篩身份、人數，也能改排序方式。
⑥ 備份！換裝置前一定要看
  • 資料只存在這台裝置的瀏覽器裡，不會上傳到任何地方。
  • 定期按「⬇ 匯出 → JSON 備份」存一份檔案。
  • 換手機或電腦時，在新裝置按「⬆ 匯入」選那個檔案就能還原。
  • 清除瀏覽器資料或使用無痕模式，記錄可能會消失。
